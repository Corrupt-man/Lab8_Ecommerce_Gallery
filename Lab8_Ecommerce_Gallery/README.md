# Responsive E-Commerce Product Gallery (Web Engineering Lab 8)

An auto-responsive e-commerce product gallery built using **HTML5** and **CSS Grid** (`auto-fit` and `minmax()`), without explicit media queries.

## Project Structure
- `index.html` — Semantic HTML5 product gallery page.
- `style.css` — CSS Grid auto-responsive layout (`minmax(250px, 1fr)`) and card hover animations.
- `README.md` — Project overview and Git/GitHub upload instructions.

## How to Run in VS Code
1. Extract the folder and open `Lab8_Ecommerce_Gallery` in **Visual Studio Code**.
2. Right-click `index.html` and choose **Open with Live Server** (or open `index.html` directly in your browser).
3. Resize your browser window to see the grid automatically adapt without media queries.
